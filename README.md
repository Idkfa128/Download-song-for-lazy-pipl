# Download-song-for-lazy-pipl
это тестовая версия скрипта которая будет дорабатываться, но в сути своей это просто скрипт для ленивых

Инструкция по установке и запуску скрипта
Шаг 1: Установка Python
Скачайте Python:
Перейдите на официальный сайт Python: python.org/downloads.
Выберите последнюю версию Python для вашей операционной системы (Windows, macOS или Linux).
Скачайте установочный файл и запустите его.
Установка Python:
Во время установки убедитесь, что выбрали опцию "Add Python to PATH" (это важно для корректной работы командной строки).
Завершите установку. 
Если вы пропустили настройку "PATH" то вот скрипт запускаемый в "cmd" для добавления переменной "setx PATH "%PATH%;C:\Users\<User>\AppData\Local\Programs\Python\Python311\Scripts"
Шаг 2: Установка необходимых библиотек
Для работы скрипта требуются следующие библиотеки:

pandas
requests
beautifulsoup4
Откройте командную строку:
В Windows: нажмите Win + R, введите cmd и нажмите Enter.
В macOS или Linux: откройте терминал.
Установите библиотеки:
Введите следующие команды одну за другой:
bash
Копировать
py -m pip install pandas
py -m pip install requests
py -m pip install beautifulsoup4
Шаг 3: Сохранение скрипта
Создайте текстовый файл:
Откройте текстовый редактор (например, Notepad, VS Code или любой другой).
Вставьте код скрипта в файл.
Сохраните файл:
Сохраните файл с расширением .py, например, download_music.py.
Шаг 4: Запуск скрипта
Откройте командную строку:
Перейдите в папку, где сохранён ваш скрипт, используя команду cd. Например:
bash
Копировать
cd C:\Users\YourUsername\Desktop
Запустите скрипт:
Введите следующую команду:
bash
Копировать
py download_music.py
Шаг 5: Проверка работы скрипта
Проверьте папку для скачивания:
Скрипт сохраняет музыку в папку F:\Audio или в ту которую вы указали для загрузки файлов. Убедитесь, что эта папка существует и доступна для записи.
Просмотрите результаты:
После завершения работы скрипта проверьте папку F:\Audio (или ваша папка) на наличие скачанных файлов.
Заключение
Теперь вы готовы к запуску скрипта и скачиванию музыки.
Также будьте внимательны данный скрипт скачивает треки только с одного сайта, данный скрипт будет дополняться для возможности скачивания с разных сайтов, некоторые песни просто не находятся на сайте, если есть предложения и рекомендации пишите <3
